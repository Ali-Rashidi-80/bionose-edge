## ۱. چکیده اجرایی

پروژه **بایونوز اج** یک موتور پردازش بویایی با قابلیت اطمینان صنعتی برای سنسورهای تعبیه‌شده در شرایط سخت است. هدف این پروژه پاسخ به یک پرسش بنیادی بود: *آیا مدار بویایی مگس سرکه می‌تواند مشکل فرسایش و تغییر رفتار شیمیایی سنسورهای گاز را روی میکروکنترلرهای کم‌مصرف حل کند؟*

با اجرای آزمایش‌های کنترل‌شده روی **۱۳٬۹۱۰ نمونه واقعی آزمایشگاهی در طول ۳۶ ماه فرسایش سنسورها** در دیتاست دانشگاه کالیفرنیا، ثابت شد که اگرچه لایه‌های اولیه بیولوژیک (تبدیل لگاریتمی وبر-فخنر و نرمال‌سازی تقسیم‌شونده لب شاخکی) برای پایداری در برابر رطوبت و دما ضروری هستند، اما کوانتیزه‌سازی باینری لوب قارچی مگس روی میکروکنترلرهای دیجیتال باعث افت ۱۵ درصدی دقت می‌شود.

با جایگزینی لایه باینری با **موتور ردیاب پیوسته برداری کسینوسی**، بایونوز اج به بالاترین رکورد دقت در این حوزه دست یافت: **۶۷.۴٪ دقت در طول ۳ سال فرسایش سنسورها** با زمان پاسخ‌دهی **۱.۸ میکروثانیه** و مصرف حافظه **کمتر از ۱ کیلوبایت رم استاتیک**.

## ۲. صورت‌مسئله صنعتی: دریفت چندساله سنسورهای گاز

سنسورهای نیمه‌هادی اکسید فلزی (<bdi>MOS</bdi>) مانند حسگرهای بوش <bdi>BME688</bdi> یا سری فیگارو <bdi>TGS</bdi>، سنسورهای استاندارد در پایش گازهای ناشی از آرک سوئیچ‌گیرها و نشت خطوط لوله هستند. با این حال، این سنسورها در محیط واقعی با سه چالش اصلی مواجهند:

1. **مسمومیت سطح و دریفت مقاومت پایه:** اکسیداسیون حرارتی و عوامل محیطی باعث تغییر چشمگیر مقاومت پایه سنسور در طول ۱ تا ۳ سال می‌شوند.
2. **تداخل‌های مشترک محیطی:** تغییرات رطوبت نسبی هوا (۱۰٪ تا ۹۰٪) و نوسانات فصلی دما باعث خطای آلارم کاذب در سنسورهای کالیبره‌نشده می‌گردد.
3. **محدودیت‌های پردازش لبه:** شبکه‌های یادگیری عمیق به دلیل نیاز به حافظه پویا، حجم بالای رم، و فراموشی فاجعه‌بار در به‌روزرسانی‌های حین کار، قابل اجرا روی میکروکنترلرهای کم‌مصرف نیستند.

## ۳. حکم علمی قطعی: ابطال ادعاهای تقلید کورکورانه از طبیعت

در مقالات نورومورفیک ادعا می‌شود که مدار لوب قارچی مگس سرکه دریفت سنسور را حل می‌کند. ما این ادعا را در یک بنچمارک کاملاً متقارن و بدون نشت داده روی دیتاست رسمی دانشگاه کالیفرنیا ایرواین به بوته آزمایش گذاشتیم.

### یافته‌های کلیدی پژوهش:
- **شکست مدل استاتیک:** کپی‌برداری ایستا از کانکتوم مگس سرکه بدون کالیبراسیون حین کار، تنها به **۲۴.۲٪ دقت** رسید و از طبقه‌بندی خطی کسینوسی (۴۰.۲٪) شکست خورد.
- **تله باینری‌سازی در لوب قارچی:** مگس در طبیعت برای مهار توان مصرفی به ۱۰ نانووات، ۹۵٪ نورون‌ها را خاموش می‌کند. اما روی پردازنده‌های دیجیتال دارای واحد پردازش اعشاری (<bdi>FPU</bdi>)، باینری کردن سیگنال‌های پیوسته سنسور، اطلاعات هندسی بردار را مخدوش می‌کند. مدل مگس حتی در مقیاس کامل زیستی (۲٬۰۴۸ سلول کنیون) به بیش از **۵۲.۴٪** نرسید و ۱۵ درصد از ردیاب کسینوسی پیوسته (**۶۷.۴٪**) عقب ماند.
- **برتری فیزیکی تبدیل وبر-فخنر:** لایه‌های ورودی وبر-فخنر و نرمال‌سازی تقسیم‌شونده لب شاخکی کاملاً تایید شدند؛ این لایه‌ها کینتیک جذب لانگمویر را خطی کرده و نرخ آلارم کاذب هوای پاک را به **۰.۰۰٪** مقید ساختند.

## ۴. معماری سیستم

### ۴.۱ جریان داده معماری

│   - خطی‌سازی فیزیک جذب شیمیایی لانگمویر               │

│   - مهار جانبی تفریقی برای حذف سیگنال زمینه           │

│   - کالیبراسیون ۵ نمونه‌ای حین کار با فرمول EMA        │

### لایه اول: ترانسداکشن وبر-فخنر
مقاومت خام سنسور را به هدایت نسبی لگاریتمی تبدیل می‌کند:
$$s_i = \ln\left(\frac{R_{0,i}}{R_i} + \epsilon\right)$$
از آنجا که فرسایش سنسورها یک ضریب ضرب‌شونده روی مقاومت ایجاد می‌کند، نسبت لگاریتمی این تغییر مقیاس را خنثی می‌نماید. آلارم‌های هوای پاک نیز با آستانه هیل فیلتر می‌شوند.

### لایه دوم: نرمال‌سازی تقسیم‌شونده لب شاخکی
با الهام از اینترنورون‌های لوکال مگس، ابتدا مهار جانبی تفریقی و سپس نرمال‌سازی تقسیم‌شونده اعمال می‌شود:
$$y_i = \frac{\max(0, s_i - \beta \cdot \bar{s})}{\sigma + \sum_{k=1}^M s_k}$$
این فرمول تضمین می‌کند که جهت بردار شناسایی گاز مستقل از رقیق یا غلیظ بودن توده گاز ثابت بماند.

### لایه سوم: ردیابی پیوسته برداری کسینوسی
این لایه بردارهای سنتروید هر کلاس گاز را در فضای پیوسته اعشاری ردیابی می‌کند:
- **استنتاج:** زاویه کسینوسی بردار سنسور با سنترویدهای مرجع سنجیده می‌شود.
- **کالیبراسیون ۵ نمونه‌ای در میدان:** با ثبت پالس گاز مرجع، سنتروید با میانگین متحرک نمایی (<bdi>Leaky EMA</bdi>) به‌روزرسانی می‌شود:
  $$\mathbf{c}_k \leftarrow (1 - \alpha) \mathbf{c}_k + \alpha \mathbf{y}$$
زمان اجرای این لایه تنها **۱.۸ میکروثانیه** است.

### لایه چهارم: پروتکل صنعتی مودباس
یک موتور پیرو استاندارد <bdi>Modbus RTU</bdi> بدون تخصیص حافظه پویا. فریم‌های درخواست را اعتبارسنجی کرده و رجیسترهای سلامت سنسور را در کمتر از ۱ میکروثانیه آماده ارسال روی باس سریال می‌کند.

## ۶. جدول رجیسترهای صنعتی مودباس

پروتکل مودباس تعبیه‌شده از توابع ۰۳ (خواندن رجیسترهای نگهدارنده) و ۰۶ (نوشتن تک رجیستر) با سرعت پاسخ‌دهی زیر یک میکروثانیه پشتیبانی می‌کند:

| آدرس رجیستر | سطح دسترسی | عنوان پارامتر | فرمت داده | توضیحات فنی |
| :---: | :---: | :--- | :---: | :--- |
| **`0x0001`** | فقط خواندنی | وضعیت سلامت سیستم | عددی ۱۶ بیتی | ۱: عادی، ۲: هشدار بوی ناشناخته، ۳: اخطار |
| **`0x0002`** | فقط خواندنی | شناسه گاز شناسایی‌شده | عددی ۱۶ بیتی | ۰: هوای پاک، ۱ تا ۶: شناسه گاز هدف |
| **`0x0003`** | فقط خواندنی | درصد اطمینان به بیسیس‌پوینت | عددی ۱۶ بیتی | ۰ تا ۱۰٬۰۰۰ (مقدار ۸۴۵۰ معادل ۸۴.۵۰٪) |
| **`0x0004`** | فقط خواندنی | پرچم بوی ناشناخته | عددی ۱۶ بیتی | ۰: گاز شناخته‌شده، ۱: بوی جدید |
| **`0x0005`** | فقط خواندنی | زمان پردازش استنتاج | عددی ۱۶ بیتی | زمان به میکروثانیه |
| **`0x0006`** | فقط خواندنی | تعداد کانال‌های فعال سنسور | عددی ۱۶ بیتی | تعداد سنسورهای متصل |
| **`0x0007`** | فقط خواندنی | شاخص فرسایش و دریفت سنسور | عددی ۱۶ بیتی | بازه ۰ تا ۱٬۰۰۰ |
| **`0x0010`** | خواندنی و نوشتنی | رجیستر دریافت فرامین | عددی ۱۶ بیتی | مقدار ۱: اعمال کالیبراسیون هوای پاک |

## ۸. راهنمای شروع سریع به زبان راست

### افزودن کتابخانه به پروژه
کتابخانه هسته را به فایل تنظیمات پروژه اضافه کنید:

```toml
[dependencies]
bionose-core = { path = "crates/bionose-core", default-features = false }
```

### نمونه کد استنتاج در سیستم‌های امبدد (<bdi>#![no_std]</bdi>)

```rust
#![no_std]

use bionose_core::{AdaptiveNoseConfig, AdaptiveNoseEngine, BioNoseTelemetry, ModbusSlave};

fn main() {
    // ۱. ساخت موتور با تنظیمات استاندارد صنعتی (۱۶ سنسور و ۶ کلاس گاز)
    let config = AdaptiveNoseConfig::industrial_default();
    let mut engine = AdaptiveNoseEngine::<16, 6>::new(&config);

    // ۲. کالیبراسیون ۵ نمونه اولیه
    let calib_sample = [12_500.0f32; 16];
    engine.train_sample(&calib_sample, 0); // آموزش کلاس صفر

    // ۳. اجرای استنتاج بی‌درنگ در ۱.۸ میکروثانیه
    let raw_sensor_reading = [12_400.0f32; 16];
    let result = engine.infer(&raw_sensor_reading);

    if !result.is_novel {
        let detected_class = result.best_class;
        let confidence = result.confidence_basis_points as f32 / 100.0;
    }

    // ۴. به‌روزرسانی حین کار سنتروید برای مهار دریفت سنسور
    engine.adapt_field_sample(&raw_sensor_reading, 0, 0.15);

    // ۵. تبدیل خودکار داده‌های خروجی به رجیسترهای مودباس
    let mut telemetry = engine.to_modbus_telemetry(&result, 2, 45);

    // ۶. پاسخ‌دهی به استعلام مودباس از باس RS485
    let slave = ModbusSlave::new(1);
    let rx_frame = [0x01, 0x03, 0x00, 0x01, 0x00, 0x04, 0x15, 0xC9];
    let mut tx_buf = [0u8; 64];

    if let Some(resp_len) = slave.process_frame(&rx_frame, &mut telemetry, &mut tx_buf) {
        // ارسال بافر tx_buf روی پورت سریال فرستنده RS485
    }
}
```

## ۹. آزمون‌های تنش و تزریق خطای خصمانه

کتابخانه دارای یک سوئیت تست تزریق خطا در مسیر تست‌های یکپارچگی است:
- **تزریق اتصال کوتاه فیزیکی:** تست سنسور با مقاومت صفر اهم بدون تولید خطای تقسیم بر صفر یا ایجاد اعداد نامعتبر.
- **تزریق قطع مدار سنسور:** تست مقاومت ۱۰ گیگااهم بدون سرریز اعشاری.
- **فازینگ و تخریب چک‌سام مودباس:** رد فریم‌های معیوب و حفظ پایداری ارتباط.
- **محافظت در برابر سرریز بافر:** رد درخواست‌های خواندن بزرگ‌تر از بافر با ارسال اکسپشن استاندارد بدون کرش.
- **تست پایداری ۱۰٬۰۰۰ سیکل تطبیق مداوم:** تضمین پایداری مقادیر سنترویدها در طولانی‌مدت.
